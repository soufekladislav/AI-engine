# Fresh AI Engine 0.7.4.2

Fresh Key je bezplatná vrstva **Propojení** mezi projekty v Lindě, Bobanovi, Edovi, Karlovi a dalších Fresh aplikacích. AI Engine projekt nevlastní a lokální projekty se sem neposílají automaticky. Uživatel je odešle výslovně z konkrétní aplikace.

Fresh aplikace mohou nově přes `/v1/fresh-key/account/bootstrap` automaticky připravit Fresh Key identitu a bezplatný účet AI Enginu. Kredity nejsou potřeba pro účet ani pro centrální správu Propojení.

Role: Vlastník / Správce / Editor / Čtenář. Vztah Klient / Agentura / Člen týmu zůstává lokální metainformace.
