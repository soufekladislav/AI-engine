Proč se částka může lišit od OpenAI / Gemini / Claude?

Engine zná jen požadavky, které prošly přes něj, a počítá je podle sazby uložené u route. Provider dashboard může navíc zahrnovat jiný časový interval, jiné API klíče/projekty, technicky neúspěšné requesty bez tokenového reportu nebo jinou skutečnou sazbu.

Proto nesrovnávám rozdíl automaticky jako chybu. Pokud se po této úpravě například OpenAI stále liší, první kontrola je stejné období + stejný API klíč + správná sazba modelu.
